# Editor Defaults (Archit): test catalogue

End-to-end cases for Editor Defaults (Archit) (`editor-defaults-archit`), run in a real Obsidian 1.15.0 in a
throwaway sandbox (`e2e/sandbox.sh`, sandbox 2, DevTools port 9312), driven over the DevTools protocol with real key
and mouse input (`Input.dispatchKeyEvent`, `Input.insertText`, `Input.dispatchMouseEvent`) where a person would type
or click; Obsidian's own settings controls (dropdowns, toggles, the hotkey delete button) are driven by their DOM
events.

- **Alone** (a fresh empty vault with only this plugin): `npm run build && e2e/sandbox.sh reset 2 && npm run e2e`,
  then `npm run e2e:restart` (A1) and `npm run e2e:fresh` (A1b, resets the sandbox).
- **Together** (with the plugins a case needs), in another sandbox folder:
  `OBS_SANDBOX_DIR=$PWD/.sandbox/together OBS_PLUGINS=SilentVoid13/Templater:<editor-multiple-lanes>:<backlinks-full-view>:<editor-outliner> e2e/sandbox.sh reset 2`,
  then `E2E_REQUIRE=templater-obsidian,editor-multiple-lanes,backlinks-full-view npm run e2e` (`<…>`: a folder with
  that plugin's build, or its GitHub release as `owner/repo`).
- One case: `node e2e/run.mjs --filter '^E1-'`. Results: `e2e/results.json`; the runner exits 1 on a failure.

The suite makes its own fixtures (`e2e/fixtures.mjs`, all under `_test/`): the notes it picks, with their aliases,
headings and blocks; the property types; a Templater template; and its own settings note (`_test/ed-settings.md`, set
as the plugin's "Settings note"), whose values the cases expect. After each case the runner puts that note back as
it was written. **Needs** names the plugins a case requires (skipped
without them); "without X" marks a case about life without X (skipped while X is enabled). **Source** points to
`SPEC.md`: its sections (Behaviour, Settings, Working with other plugins) and decisions (1–7).

Surfaces: **tab** = a normal tab, **lanes** = an Editor Multiple Lanes card (one smoke case per feature),
**canvas-text** / **canvas-file** = a Canvas text card / file card being edited, **Bases** = a `.base` table tab.

**Final runs: 2026-11-09.** Alone: 77 of 94 cases run (17 need Templater, Backlinks Full View, Editor Multiple Lanes or BRAT), all PASS, no console error; A1 and A1b PASS. Together (Templater 2.27, BRAT 2.2, Editor Multiple Lanes, Backlinks Full View, Editor Outliner; `E2E_REQUIRE` for the first four): 88 of 94 run, all PASS, no console error (the 6 others are about life without Templater or Backlinks Full View).

Status: PASS / FAIL / MANUAL (needs a person: native UI the harness can't drive) / SKIP alone (runs together).
